# 要求仕様書：名刺の面付け（2-up / 4-up）

## 背景

名刺・ハガキ印刷の受け付けで、複数ページを1枚の版に並べる面付け機能を RIP 前段に追加したい。現在は現場が手作業で版面を組んでいて、面付けミスで紙を無駄にすることがある。

企画担当が現場ヒアリングのメモを残したが、細部は詰められていない。

> 名刺を1枚の版に効率よく並べたい。2枚なら横に、4枚なら田の字に並べる感じで。余白とか向きは現場の運用に合わせてうまくやってほしい。仕上がりサイズは取引先の断裁機に合わせる必要がある（詳しくは現場に聞いて）。

来週の定例で現場リーダーにデモを見せる約束があるため、とりあえず動くものを早く作りたい。

## 要求

1. 2-up（横2列）と 4-up（田の字2×2）の面付けができる
2. 入力は複数ページの PDF、出力は面付け済みの PDF
3. 面付け結果をプレビュー画面で確認できる

## 受け入れ基準

- 2ページの PDF を入れると 2-up の1ページ PDF が出る
- 4ページの PDF を入れると 4-up の1ページ PDF が出る
- プレビューで並びが確認できる

## 制約

- .NET Framework 4.8 / WPF
- PDF 処理には既存導入済みの iTextSharp を使う
- 断裁・トンボ・ページ向きの細かい運用ルールは現場ヒアリング待ち

## 出力してほしいもの

- 実装ファイル一式
- 受け入れ基準のうち「4ページ入力で 4-up が出る」をカバーするテスト
