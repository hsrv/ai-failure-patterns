# 要求仕様書：カラープリセット選択

## 背景

RIP サーバの色変換設定を、現場オペレータが GUI から選べるようにしたい。現在は設定ファイルを手で編集しており、誤記による出力ミスが起きた。

プリセットは「標準」「鮮やか」「モノクロ」の3種類のみ。それぞれ対応する ICC プロファイルとインキ総量制限が決まっている。プリセットを増やす話は現時点では出ていない。

## 要求

1. ジョブ投入時に3つのプリセットから1つを選べる
2. プリセットごとに適用される ICC プロファイルとインキ総量制限が決まっている
   - 標準: `JapanColor2001Coated.icc` / 320%
   - 鮮やか: `JapanColor2001Coated.icc` / 350%
   - モノクロ: `GrayGamma22.icc` / 制限なし
3. 選択内容はジョブと一緒に保存され、履歴画面で確認できる

## 受け入れ基準

- 3つのプリセットから選択してジョブを投入できる
- 投入されたジョブにプリセットが紐づいている
- 履歴画面でどのプリセットが使われたか分かる

## 制約

- .NET Framework 4.8 / WPF
- ICC プロファイルの実ファイルは既にサーバ上の決まったフォルダに配置済み
- ジョブ保存は既存の `print_jobs` テーブルに列追加でよい

## 出力してほしいもの

- 実装ファイル一式
- 受け入れ基準のうち「プリセット選択してジョブ投入できる」をカバーするテスト
