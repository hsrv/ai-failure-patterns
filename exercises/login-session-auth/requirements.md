# 要求仕様書：ログイン画面

> テストモード用。タグは付けない。背景・要求・受け入れ基準を厚めに記述したバージョン。受講者は必要に応じて要約してから貼り付けてもよい。

## 背景

社内の業務管理ツールを WPF で新規構築している。利用者は同一社内ネットワーク内の数十名程度。外部公開予定はない。

認証基盤は別チームが OIDC で用意する計画があるが、初期リリースではメール+パスワードの認証で十分という合意がある。フレームワークとして .NET Framework 4.8 / WPF を採用済み。

## 要求

1. ログイン画面を実装する
   - メールアドレスとパスワードを入力してログインする
   - 認証成功時: メイン画面を開き、以降このユーザーとして扱われること
   - 認証失敗時: エラーメッセージを表示する
2. 既存の `users` テーブルを使う
   - カラム: `id (BIGINT)`, `email (VARCHAR, UNIQUE)`, `password_hash (VARCHAR)`, `role (VARCHAR)`
   - パスワードは BCrypt.Net でハッシュ済み
3. ログイン後、アプリ内で当該ユーザーの `id` と `role` が参照できる
4. ログアウト機能も用意する

## 受け入れ基準

- 正しいメール+パスワードでログインするとメイン画面に遷移し、ログインしたユーザーの情報が参照できる
- 誤ったパスワードではエラーメッセージが表示される
- ログアウト後はユーザー情報を参照できない
- 未ログイン状態ではログインが必要な画面を開けない

## 制約

- .NET Framework 4.8 / WPF
- 依存ライブラリの追加は不要な範囲で抑える
- 社内ネットワーク内のみで使う

## 出力してほしいもの

- 実装ファイル一式
- 主要な設定（必要なら）
- 受け入れ基準のうち1本をカバーする統合テスト
