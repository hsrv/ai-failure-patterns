# 要求仕様書：商品マスタ一括更新画面

## 背景

中堅SIerの社内システム部門。.NET Framework 3.5 時代のコードベースを .NET Framework 4.8 / WPF に移行している最中で、新規機能は C# 7.3 で書く方針。チームは7名、内訳はC#歴10年以上が2名、C#歴5年が2名、C#歴2年以下が3名。

過去にラムダ式と LINQ を多用したコードが入った際、C#歴の浅いメンバーから「読めない」「デバッグできない」というクレームが出た。`var` や null 合体演算子も同様に「昔の書き方の方がわかりやすい」という声があった。

新規に「商品マスタの一括更新画面」を実装することになった。

## 要求

1. 管理画面から複数商品の価格を一括更新する（商品IDと新価格の一覧を入力、またはCSV取込）
2. 更新対象は商品IDと新価格のリスト
3. 商品IDが存在しない・新価格が0以下・現在価格との差が50%を超えるものは更新を拒否する
4. 拒否された商品は結果一覧に理由付きで表示する
5. 更新成功した商品も結果一覧に表示する（更新前と更新後の価格を含む）

## 受け入れ基準

- 100件のうち正常80件・拒否20件のデータを投入すると、80件が DB 更新され、結果一覧に成功80件と拒否20件（理由付き）が含まれる
- 拒否理由は「商品IDが存在しない」「新価格が0以下」「価格差が50%を超える」の3種類を区別できる
- 1回の一括更新で最大1,000件まで扱える

## 制約

- .NET Framework 4.8 / WPF
- チームの平均読解力に配慮した可読性を維持する
- 既存コードのスタイルはfor文中心の手続き的コードが多い

## 出力してほしいもの

- 実装ファイル一式
- 採用したコーディングスタイルの理由
- 受け入れ基準のうち「正常80件・拒否20件のリクエスト」をカバーするテスト
