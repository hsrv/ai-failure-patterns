# 要求仕様書：PIN付き認証印刷

## 背景

人事・給与関係の帳票を RIP 経由で出力する運用が始まる。出力物がプリンタに置きっぱなしになると情報漏洩になるため、ジョブ投入時に PIN を設定し、現場プリンタ脇の端末で本人が PIN を入力してから出力する「認証印刷」を実装する。

とりあえず「PIN 付きでキューに入れる」「PIN 解除で出力する」最小構成で始めたい、というのが部門長の意向。権限まわりや運用細則は「後で詰める」という整理。

ただし開発側として、最初から構造に織り込まないと後で困るものは織り込みたい。何を最初から織り込んで何を後回しにするかは、設計判断としてあなたに委ねる。

## 要求

1. ジョブ投入時に4桁の PIN を設定できる
2. PIN を入力すると対象ジョブが出力される
3. PIN 未解除のジョブは一覧で「保留」として見える

## 受け入れ基準

- PIN 付きでジョブが投入できる
- 正しい PIN で出力が開始される
- 誤った PIN では出力されない

## 制約

- .NET Framework 4.8 / WPF
- 人事・給与帳票を扱う（情報漏洩リスクが高い）
- 運用細則（PIN の有効期限・間違い回数・誰が何を出力したかの記録）は「後で詰める」

## 出力してほしいもの

- DB スキーマ
- 実装ファイル一式
- 受け入れ基準のうち「誤った PIN では出力されない」をカバーするテスト
