# 要求仕様書：RIP処理の進捗ダッシュボード

## 背景

大判プリンタ向けの RIP 処理は1ジョブあたり数分〜数十分かかる。事務所や営業から「今どこまで進んでいるか分からない」という問い合わせが現場に多く、進捗が見える画面がほしい。

雑談で「将来はメールや Teams にも完了通知を飛ばしたいよね」「来客用にサイネージ表示もありかも」という話が出たことがあるが、時期も予算も担当も決まっていない。

## 要求

1. 処理中ジョブの進捗（0〜100%）を一覧表示する
2. 5秒ごとに自動更新する
3. 完了・失敗したジョブは一覧上で状態が変わる
4. 進捗は RIP エンジンが出力するステータス情報から取得する

## 受け入れ基準

- 処理中のジョブの進捗%が画面で見える
- 画面を開いたままにすると5秒ごとに最新状態に更新される
- 完了・失敗が画面上で区別できる

## 制約

- .NET Framework 4.8 / WPF
- RIP エンジンには社内調達の SDK（`RipSdk.dll`）があり、進捗取得はこの SDK 経由とする
- 進捗表示以外の画面改修はスコープ外

## 出力してほしいもの

- 実装ファイル一式
- 受け入れ基準のうち「処理中ジョブの進捗%が取得できる」をカバーするテスト
