# 要求仕様書：旧ジョブチケット形式の取り込み

## 背景

10年以上前の旧印刷管理システム（Win32 時代の資産）で使われていたジョブチケット XML（v1 形式）を、新しいジョブチケット v2 形式と併せて取り込めるようにしたい。

旧形式を発行していたツールはとっくに保守切れで、新規に v1 チケットが発行されることは無い。ただし現場から「過去5年分の古いチケットを再登録したい話が以前あった気がする」という曖昧な情報がある。実際に再登録するかは誰も確認していない。

## 要求

1. v2 形式（`{"version": 2, "job": {...}, "paper": {...}}`）の XML/JSON チケットを取り込む
2. v1 形式（`<ticket><job .../><paper .../></ticket>` のフラットな XML）も取り込めるとよい
3. 取り込んだチケットはジョブとしてキューに登録する

## 受け入れ基準

- v2 形式のチケットが正しく取り込まれる
- v1 形式のチケットもエラーにならず取り込まれる

## 制約

- .NET Framework 4.8 / WPF
- JSON には Newtonsoft.Json、XML には LINQ to XML を使う
- 取り込み対象のチケットは社内ストレージの決まったフォルダに置かれる

## 出力してほしいもの

- 実装ファイル一式
- 受け入れ基準のうち「v2 形式が取り込まれる」をカバーするテスト
